# interfaces-graficas-com-tkinter

Repositório com exemplos e exercícios voltados para prática de interfaces gráficas usando a biblioteca Tkinter, nativa do Python.

> Projeto criado para estudos. Baseado em conteúdos de cursos e prática pessoal.

## O que este repositório mostra

- Criação de janelas simples com `Tkinter`
- Uso dos principais gerenciadores de layout:
  - `place`
  - `pack`
  - `grid`
- Posicionamento de widgets (botões, labels, entry, etc.)
- Eventos e manipulação de dados
- Construção de telas com entradas de login e senha
- Parâmetros como `anchor`, `side`, `fill`, `expand`, `rowspan`, `columnspan`, `sticky`
